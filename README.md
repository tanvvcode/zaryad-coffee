# Вебсайт 2

Экспорт полной структуры проекта из Miff для выбранной актуальной версии.

## Локальный запуск (Vite + React + Tailwind CSS)

```bash
npm install
npm run dev
```

Сборка production-бандла:

```bash
npm run build
```

## Готовая автономная версия

Файл `preview/index.html` содержит полностью собранный HTML данной версии — его можно открыть напрямую в браузере без установки зависимостей.
